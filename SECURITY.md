# Security policy

ARCTIC-0 archive/tooling v1.0.0 is supported with security and data-integrity
fixes. Report vulnerabilities or accidental disclosure of protected evaluation
material privately to xLagerFeuer at alexander.zhdanoff@gmail.com.

Do not open a public issue containing exploits, credentials, private benchmark
samples, target outputs that are not already in the published answer key, or
other sensitive evaluation material. Include affected versions, reproduction
steps, and impact in the private report.
